# 变更日志

所有重要变更记录在本文件中。

格式参照 [语义化版本](https://semver.org/)。

## [0.60.1] - 2026-11-23

### 新增
- **组合液执行贴**：每张执行贴最多逐行显示 4 个药品组员，包含序号、药品名称、剂量及共享用法；“氯化钠 + VB + VC + 氯化钾”可在单张 60×60mm 标签完整呈现
- **超大医嘱组自动续页**：超过 4 项时按每页 4 项生成多张独立标签，右上角标注 `1/2、2/2`；每页重复患者信息、住院号条码、开单/核对信息和盖章区
- 执行贴预览入口仅显示在根医嘱行，子医嘱不再重复生成同一组标签

### 优化
- 组员名称按长度自动缩小字号，剂量独立右对齐；组级途径、频次和滴速只展示一次，提升有限标签空间利用率

### 测试
- 单药、4 项组合液、5 项续页、8 项双页、长药名和从子医嘱归一到根医嘱场景均通过尺寸、分页、条码及内容完整性回归

## [0.60.0] - 2026-11-23

### 新增
- **成组药品执行贴数据**：执行贴接口自动把子医嘱归一到根医嘱，按根项、`group_seq`、ID 顺序返回完整有效药品组，支持“氯化钠 + VB + VC + 氯化钾”等组合液
- **组内发药识别**：根医嘱可识别任一子医嘱的已发药/已送达记录，不再因发药记录落在子项而缺少执行贴入口
- 接口返回 `root_order_id`、`group_items`、`group_size`，为多标签续页和组内查对提供稳定契约

### 安全
- 草稿、作废、已停止的组员不会进入执行贴；从子医嘱 ID 直接请求时仍执行主医嘱状态和患者病区权限校验

### 测试
- 单药、根+1 子项、根+3 子项、从子项进入、组内子项发药五种数据结构通过接口查询回归

## [0.59.13] - 2026-11-23

### 修复
- **执行贴正文空白行**：正文区域由强制填满剩余高度改为按药品内容自适应高度，短医嘱不再在边框内部产生多余空白行，长药名仍支持最多三行
- **正文与条码粘连**：标签五个区域增加至少 1mm 行间距，剩余空间分配到元素之间，正文边框与下方条码不再连接或产生重叠观感
- 检验分类继续以 `lab_catalog.category` 为唯一口径，不引入标本类型或执行科室替代值

### 测试
- 短医嘱正文底部仅保留模板内边距；正文与条码实际间距大于等于 1mm；三行长药名、盖章区及 60×60mm 纸张均无溢出

## [0.59.12] - 2026-11-23

### 优化
- **检验标签首行四列**：姓名靠左、床号靠右，性别和年龄作为两个独立元素居中显示
- **检验项目/分类双栏**：倒数第二行左侧显示检验项目，右侧显示真实检验分类；两侧分别截断，互不挤占
- **开单信息完整化**：最下一行左侧显示开单医生，右侧显示完整 `YYYY-MM-DD HH:mm:ss` 开单日期时间
- **执行贴信息顺序优化**：调整为患者信息 → 医嘱正文 → 住院号条码 → 开单/核对及盖章，更符合床边查对阅读顺序；正文区域增加约 5mm 高度并支持三行药名
- **盖章区适配长形印章**：移除预设执行护士姓名，盖章框改为 21×7mm（3:1），与左侧两行信息齐平；提示文字改为浅灰色，减少对实体盖章的干扰

### 测试
- 首行四元素、项目/分类、医生/完整时间左右边界对齐；执行贴正文先于条码、无执行护士姓名、21×7mm 盖章框及两种纸张无溢出均通过浏览器回归
