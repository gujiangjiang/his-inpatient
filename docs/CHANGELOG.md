# 变更日志

所有重要变更记录在本文件中。

格式参照 [语义化版本](https://semver.org/)。

## [0.17.0] - 2026-10-12

### 新增
- **患者资金体系 (预交费用 / 可透支 / 已用自动计算)**：迁移 032 `patients.prepay_fee`（实缴预交）与 `overdraft_limit`（可透支，默认 1000）；`patients/funds` 资金概览接口（可用余额 = 预交 + 可透支 − 已用，已用按有效医嘱项目库价格自动累计，收费功能后续完善）；patients/save 支持可选维护两字段
- **费用悬停浮窗**：患者信息栏「费用」悬停显示预交 / 已用 / 可透支 / 可用余额，余额为负红色提示「预缴金不足」（检验检查可开、药房摆药将拦截）
- **预缴金不足联动**：检验/检查申请面板打开时右上角 toast 提醒（不阻断开单，可正常开具）；药房摆药前校验余额——不足则摆药失败并提示可用余额（护士核医嘱不受影响）

## [0.16.6] - 2026-10-12

### 变更
- 成组医嘱悬停整组联动高亮：鼠标经过组内任意一行（主或子），整组同时高亮（原仅悬停行高亮，主/子观感割裂）

## [0.16.5] - 2026-10-12

### 修复
- 成组医嘱高亮色条错位：组选中左侧色条原按每行首格绘制，子医嘱行首格是内容格导致子医嘱前方凭空出现选中样式；现仅绘制在组首勾选列（rowspan 覆盖整组），整组一条连续色条

## [0.16.4] - 2026-10-12

### 修复
- **申请类医嘱锁定编辑**：检验/检查/会诊申请生成的医嘱（is_auto_generated）不再允许切换临时/长期、修改剂量/途径/频次/执行时间、快捷删除与详情编辑；操作菜单不再提供提交/删除/复制（经申请页面管理）
- 迁移 031 回填历史申请类医嘱标记（会诊按关联单精确识别；检验/检查按项目库名称匹配），历史草稿统一提交为待核对

## [0.16.3] - 2026-10-12

### 变更
- **申请类医嘱默认直接提交**：检验/检查/会诊申请自动生成的医嘱一律直接提交（pending 待护士核对），不再有草稿态；申请面板按钮收敛为单一「开具」
- 仅医嘱工作站手工开具的药品/非药品医嘱（及处方面板）保留「草稿 → 提交」流程
