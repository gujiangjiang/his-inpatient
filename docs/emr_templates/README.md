# 内置病历模板文件 (导出参考)

本目录为系统内置住院病历模板的 **JSON 导出文件**（参考/备份/分发用）。

- 真源：`api/scripts/emr_template_defs.php`（种子脚本 seed_emr_templates.php 使用同一份定义建库）
- 重新导出：`php api/scripts/export_emr_templates.php`
- 说明：模板中的 `header.hospital` 导出时取站点配置的医院名称；`slot` 可携带 `opts`
  选项列表（下拉选择）；`dyn` 为动态只读项（BMI 自动计算 / 初步诊断同步 / 医师签名）。

| 文件 | 分类 | 说明 |
| --- | --- | --- |
| 01_入院记录 | 入院记录 | 12 项患者信息（与病案首页单向同步）+ 完整入院记录 |
| 02_再次或多次入院记录 | 入院记录 | 同上版式 |
| 03_24小时内入出院记录 | 入院记录 | 24h 入出院专用 |
| 04_24小时内入院死亡记录 | 入院记录 | 24h 死亡专用 |
| 05_日常查房记录 | 病程记录 | 日常病程 |
| 06_上级医师查房记录 | 病程记录 | 上级查房 |
| 07_首次病程记录 | 病程记录 | 病例特点/诊断依据/鉴别诊断/诊疗计划 |
| 08_医患沟通记录 | 沟通记录 | 沟通时间地点人员内容意见+双方签名 |
| 09_出院记录 | 出院记录 | 按规范出院小结 |
